ALTAF Exchange · ALTF token · ALTAF native network

1. Summary

ALTAF is a crypto ecosystem made of three parts that work together:

  • ALTAF Exchange — a full trading platform: spot, futures, P2P, convert, Earn, Launchpad, Token Factory, listings, copy trading, trading bots, ALTAF Pay, governance, API keys and real-time market data.
  • ALTF — a TRC20 token on TRON with a fixed supply of 21,000,000 and a verified, public contract.
  • ALTAF Network — a native proof-of-work blockchain that anyone can mine, connected to the exchange by a bridge.

The goal is a North-African-founded exchange and network that is transparent by design: verified contract code, public proof of reserves, and partner-run infrastructure with on-chain governance rights.

Partner servers

The contract supports up to 16 partner servers. When the operator opens a server, 1,000,000 ALTF is allocated to it and locked. The lock releases 100 ALTF every 90 days, so partner allocations enter circulation slowly and predictably. Closing a server returns its still-locked balance to the contract reserve. All of this is enforced by the contract, not by promises.

On-chain views: reserve(), circulatingSupply(), transferable(address).

3. ALTAF Network (native chain)

  • Consensus: proof of work with two mining lanes — a CPU algorithm for ordinary computers and SHA-256 for ASIC machines. Each lane produces half of the blocks, so home miners are not pushed out by industrial hardware.
  • Launch emission: 2,000,000 coins mined over the first 12 months (≈5,480 per day), with a cap per mining address.
  • Founder share: 10% of each block reward.
  • Fees: half of every transaction fee goes to the miner, half is burned.
  • After year one: very small emission, designed so that monthly new coins stay below the previous month's burn. Total supply never exceeds 21,000,000; burning stops at 10,000,000.
  • Addresses start with A. Public node and explorer: altafnet.187-126-9-68.sslip.io; stratum mining on port 3333; Windows miner available.
  • Bridge: ALTF can move between TRON (TRC20) and the native network through the exchange.

5. Security and transparency

  • Withdrawal signing runs in a separate signer service; user deposit addresses are derived per user.
  • 2FA (TOTP) for accounts and withdrawals.
  • Hot wallet above a set limit is moved to a cold address.
  • Proof of reserves: a public page compares total user balances with the platform's on-chain wallets, refreshed every 10 minutes.
  • Encrypted daily backups stored off-server, with tested restore.

6. Governance

Owners of active partner servers vote on platform proposals: one active server = one vote, 7-day votes, 2FA required. The founder holds a veto; the first four partners are founding partners, and any two of them together can override the founder's veto.

7. Partners — server owners

ALTAF is built with its partners. The network has 17 servers: the founder's server plus 16 partner servers.

  • Every partner server receives 1,000,000 ALTF, allocated automatically by the contract when the server is opened.
  • Every active server holds one vote in platform governance; the first four partners are founding partners with a shared veto.
  • Platform fee revenue is shared by the first servers: founder server 50%, second 25%, third 15%, fourth 10%.
  • Any partner can join with one command: curl -fsSL https://altafnet.187-126-9-68.sslip.io/install.sh | sudo bash installs a full ALTAF node that connects to the network automatically.
  • If a server is closed, its locked coins return to the reserve for the next partner, so seats always stay filled.
